CC Solutions website — deployment guide

1. Sign in at https://github.com
2. Create a NEW PUBLIC repository named cc-solutions.
3. Upload index.html, CC_Solutions.docx, and README.txt from this folder to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, select "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait a few minutes, then open the URL shown in Pages settings.
   It will look like https://YOUR-USERNAME.github.io/cc-solutions/

GitHub Pages sites are public. Do not upload private or sensitive information.
